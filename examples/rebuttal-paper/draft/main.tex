\begin{abstract}
Long-context inference for large language models suffers from prohibitive
memory and latency costs, scaling quadratically with sequence length. Existing
approaches either drop tokens via fixed heuristics (sacrificing accuracy) or
retain all tokens (sacrificing speed). We introduce \textsc{AttnRoute}, a
lightweight learned router that selects which KV-cache entries to attend to,
trained jointly with the base model. On three long-context benchmarks
(LongBench, RULER, InfiniteBench) using Llama-2-7B, \textsc{AttnRoute} reduces
inference latency by 30\% relative to full attention while achieving
$+1.8$ pp accuracy on LongBench, $+2.4$ pp on RULER, and $+2.5$ pp on
InfiniteBench compared to FlashAttention-2. All gains are significant at
$p<0.05$ (paired Wilcoxon, $n=5$). Code is released at
\url{https://anonymous.4open.science/r/attention-routing-rebuttal/}.
\end{abstract}
