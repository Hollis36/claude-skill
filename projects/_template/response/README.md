# Response to Reviewers

## 文件命名

- `rebuttal_round1.md` — 第一轮 rebuttal
- `rebuttal_round2.md` — 第二轮（若有）
- `response_letter.md` — 期刊 major revision 回信
- `reviewer_<N>.md` — 单独 reviewer 草稿

## 写作指南

完整模板见 `knowledge/templates/rebuttal.md`。

## 一般工作流

1. **收到 reviews 当天**：通读 + 标记所有问题（不要急着回应）
2. **第二天**：列 TODO，决定哪些补实验、哪些纯回应
3. **rebuttal 期一半时间**：补实验
4. **后半期**：写 rebuttal 草稿
5. **截止前 24h**：通读、检查字数、提交

## 备份策略

每次提交前 `cp rebuttal_round1.md rebuttal_round1_submitted_YYYY-MM-DD.md`，留存提交版本。
