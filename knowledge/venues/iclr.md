# ICLR

International Conference on Learning Representations — 与 NeurIPS / ICML 并列三大 ML 顶会。

## 基本信息

- **官网**：https://iclr.cc
- **OpenReview**：https://openreview.net/group?id=ICLR.cc
- **评审制度**：**公开评审**（OpenReview）— 评论可见，但 reviewer 匿名
- **接收率**：约 30–35%
- **特色**：开放讨论，所有 review + rebuttal + comment 公开

## Timeline（典型）

| 阶段 | 时间 |
|------|------|
| Paper Submission | 9 月底 |
| Reviews Released | 11 月初 |
| Author Response (rolling) | 11 月中 – 12 月初 |
| Final Decision | 1 月底 |
| Camera-ready | 3 月初 |
| 会议召开 | 4 月底 / 5 月初 |

## 格式

- **模板**：ICLR LaTeX style
- **主文长度**：9 页（review）→ 10 页（camera-ready）
- **References / Appendix**：不限
- **匿名**：double-blind 评审，但**论文公开可见**

## 必填材料

1. **Code 链接**（强烈鼓励，submission 时填）
2. **Ethics Statement**
3. **Reproducibility Statement**
4. **数据 / model release 计划**

## 评审

- **Score 1–10**：
  - 10: strong accept
  - 8: accept
  - 6: marginally above acceptance
  - 5: marginally below
  - 3: clear reject
- **Confidence 1–5**
- **OpenReview 公开讨论**：
  - 任何人（非 reviewer）可以发 public comment
  - 作者可以 tag 其他研究者参与
  - reviewer 之间可以互相讨论

## Rebuttal 策略（ICLR 特有）

- **Rolling discussion period**（2–3 周，比 NeurIPS / ICML 长）
- **多轮交流**：可以追加实验、回应每条评论
- **公开战略**：rebuttal 内容公开，措辞要更专业（领域同行都在看）
- **拉同行支持**：可以 @ 相关研究者发 public comment

## Track

- **Main Track**
- **Workshop**（截止 1 月）
- **Tiny Papers**（短论文 track）
- **Blog Post Track**（2022+）

## OpenReview 写作差异

- 评审公开 = **质量更高 reviewer**（不会乱写）
- 作者可以**展示已被 highlight 的赞美**
- **撤稿仍留痕**（提交即公开，慎重）
- 已 reject 的可以**revise 后下一届再投**，会比较公平

## 与 NeurIPS / ICML 差异

| 维度 | ICLR | NeurIPS | ICML |
|------|------|---------|------|
| 评审透明度 | 公开 | 不公开 | 不公开 |
| Rebuttal | 多轮 / 长 | 1 轮 / 6 页 | 1 轮 / 5000 字 |
| 接收率 | ~32% | ~26% | ~25% |
| 偏好 | representation learning | broad ML | 偏理论 |
