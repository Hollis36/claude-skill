# ICML

International Conference on Machine Learning — ML 三大顶会之一。

## 基本信息

- **官网**：https://icml.cc
- **OpenReview**（部分年份）/ 内部系统：以官网为准
- **评审制度**：double-blind，3–4 位 reviewer + 1 AC + 1 SAC
- **接收率**：约 24–27%
- **录用 → 出版**：PMLR (Proceedings of Machine Learning Research)

## Timeline（典型，以官网为准）

| 阶段 | 时间 |
|------|------|
| Abstract Submission | 1 月下 |
| Full Paper Submission | 2 月初 |
| Author Response | 4 月中 |
| Author Notification | 5 月初 |
| Camera-ready | 6 月初 |
| 会议召开 | 7 月中 |

## 格式

- **模板**：ICML LaTeX style（PMLR template）
- **主文长度**：8 页（review）→ 9 页（camera-ready，含 ethics statement）
- **References / Appendix**：不限页数
- **匿名**：严格 double-blind

## 必填材料

1. **Impact Statement / Broader Impact**（2022+ 强制）
2. **Reproducibility Statement**（建议）
3. **Code / Data 链接**（鼓励）
4. **LLM 使用声明**（近年加强）

## 评审

- **Score 1–10**：6 通常是 borderline
- **Confidence 1–5**
- **AC 主导决定**，SAC 二审
- **Spotlight / Oral** 由 AC 提名

## Rebuttal

- **5000 字符限制**（严格）
- **2 轮** discussion（部分年份）：第一轮回应 reviewer，第二轮 reviewer 之间讨论
- 重点：补实验、改图、回应所有 reviewer，**不留遗漏**

## Track

- **Main Track**
- **Workshop**（截止 3–4 月，会议同期）
- **Tutorials**（受邀）

## 与 NeurIPS 差异

| 维度 | ICML | NeurIPS |
|------|------|---------|
| 时间 | 上半年（提交早）| 下半年（提交早夏） |
| 风格 | 略偏理论 | 略偏经验 |
| Rebuttal | 字符严格限制 | PDF 6 页 |
| Track | Main + Workshop | Main + D&B + Workshop |
| 主办 | IMLS | NeurIPS Foundation |
