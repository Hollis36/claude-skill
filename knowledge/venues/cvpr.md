# CVPR

IEEE/CVF Conference on Computer Vision and Pattern Recognition — CV 顶会。

## 基本信息

- **官网**：https://cvpr.thecvf.com
- **CMT 系统**：Microsoft CMT
- **评审制度**：double-blind，3 位 reviewer + AC + SAC
- **接收率**：约 22–27%
- **录用 → 出版**：CVF Open Access + IEEE Xplore

## Timeline（典型）

| 阶段 | 时间 |
|------|------|
| Paper Submission | 11 月初 |
| Author Response (Rebuttal) | 1 月中 |
| Author Notification | 2 月底 |
| Camera-ready | 3 月底 |
| 会议召开 | 6 月中 |

## 格式

- **模板**：CVPR LaTeX style（IEEE 双栏）
- **主文长度**：8 页（review）+ references 不限
- **匿名**：double-blind
- **重新提交**：CMT 系统识别多次提交，需声明 prior submission

## 必填材料

1. **Paper ID**（CMT 分配）
2. **Subject area** 分类
3. **Supplementary**（视频 / 代码 / 附录，ZIP）
4. **Conflicts of Interest**（详细，与 reviewer 列表交叉）
5. **Author profile**（research area、prior publications）

## 评审

- **Score 1–5**：
  - 5: definite accept
  - 4: probable accept
  - 3: borderline
  - 2: probable reject
  - 1: definite reject
- **Confidence 1–5**
- **AC 决定**，SAC 审议
- **Highlight / Oral** 比例约 1–2% / 10%

## Rebuttal

- **1 页 PDF**（严格，文字 + 1 张图）
- **截止 1 周**
- 只能回应 review 中的事实性问题、补结果，不能引入全新方法
- 重点：1 张关键 figure / table

## Track

- **Main Conference**
- **Workshops**（截止 3 月，会议同期）
- **Tutorials**

## 与其他 CV 顶会差异

| 维度 | CVPR | ICCV | ECCV |
|------|------|------|------|
| 频率 | 年度 | 隔年（奇数年） | 隔年（偶数年） |
| 地点 | 北美 | 全球轮换 | 欧洲 |
| 接收率 | ~25% | ~25% | ~25% |
| 投稿月 | 11 月 | 3 月 | 3 月 |
| Camera 时间 | 3 月 | 7 月 | 7 月 |

## 检查清单

- [ ] CVPR 模板，8 页主文
- [ ] PDF 匿名（包括引用 "Smith et al." 形式）
- [ ] Supplementary（视频建议 30s–2min）
- [ ] CMT conflicts 准确填写（漏报会被 desk reject）
- [ ] References 用 IEEE 编号格式 `[1]`
- [ ] 数学公式编号统一
- [ ] 数据集 license 兼容 release（CVF Open Access）
